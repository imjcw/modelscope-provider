- **但条目名是 `web\favicon.ico\favicon.ico`**（嵌套两层）——PyInstaller 的 `--add-data 源;目标` 中**目标参数是"目录"而非"文件路径"**，build_exe.py 写成 `web/favicon.ico` 被当目录，文件被放进 `web/favicon.ico/favicon.ico`。
- 后果：运行时 `_make_icon_path()` 找 `_MEIPASS/web/favicon.ico`，那是个**目录**，`os.path.isfile()` False → 回退到旧内置 Base64 图标（"AI"样式：青顶+品红中+青底，16x16 下糊成"蓝色三角"）→ 用户看到的就是它。
- **修复**（三处 add-data 目标都从 `web/favicon.ico` 改为 `web`）：
  - `build_exe.py` L65：`f"{WEB / 'favicon.ico'}{sep}web"`
  - `AIProvider.spec` L5：`('D:/.../web/favicon.ico', 'web')`
  - `AIProvider.exe.spec` L8：`('web/favicon.ico', 'web')`
- 验证：py_compile OK；模拟 `_MEIPASS/web/favicon.ico` 路径存在且是文件。
- **教训**：PyInstaller add-data/spec datas 的目标永远写"目标目录"；`.spec` 中 `icon=['...favicon.ico']` 是列表形式（EXE 资源图标），与 datas 无关。

## 🐛 修复：自绘菜单点击外部不消失 + 菜单项点击无效
用户反馈两个 bug：点击外部菜单不消失、点击菜单功能不生效。根因（自绘 popup 菜单经典坑）：
1. **点击菜单项无效**：`SW_SHOWNOACTIVATE` 未激活窗口 → Windows 把第一次点击"吃掉"用于激活窗口，WM_LBUTTONUP 不触发。修复：`SetForegroundWindow` + `SetActiveWindow` + `ShowWindow(SW_SHOW)` 先激活。
2. **点击外部不消失**：未 `SetCapture` → 外部点击鼠标消息发给被点窗口，菜单收不到。修复：`SetCapture(self.hwnd)` 捕获鼠标，`GetCapture()==self.hwnd` 时 `ReleaseCapture` 释放；`WM_LBUTTONDOWN`/`WM_LBUTTONUP` 判定坐标在窗口外则 `_close()`。
3. **坐标转换**：捕获期间 WM_MOUSEMOVE/LBUTTONUP 的 lParam 是**屏幕坐标**非客户区坐标。新增 `_screen_to_client()`：符号扩展处理负坐标 + `ScreenToClient` 转换。命中测试用转换后坐标。
4. 新增 `WM_ACTIVATEAPP`（wparam=0 切走时关闭）兜底。

**验证**：`py_compile run.py` OK。需重新打包后实测。
- **用户明确表示：数据迁移他自己处理，不需要代码自动迁移。**
